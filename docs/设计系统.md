# StarHub 设计系统

> 本项目 **统一遵循 DeepSeek Harness 的设计理念**,不再维护独立的品牌设计语言。
> 所有 UI(外观、组件、颜色、字体、阴影、动效)一律复用 DeepSeek Harness(下称 DSH)的
> `ui-theme` 设计平台与 `--dsw-*` 语义 token。

## 1. 唯一事实来源

| 主题 | 位置 |
|---|---|
| DSH 设计平台 token(静态色阶 / 语义别名 / 排版 / 动效 / 阴影 / 滚动条) | `vendor/deepseek-harness/packages/client/ui-theme/src/styles/` |
| DSH 样式规范(权威) | `vendor/deepseek-harness/docs/web-styling.md` |
| DSH 品牌素材规范(命名与宣传) | `vendor/deepseek-harness/BRAND_GUIDELINES.md` / `BRAND_GUIDELINES.zh.md` |
| 浅色 / 深色主题偏好 | DSH 设置面板「外观」(`package: client/ui-theme`) |

## 2. 规则(与 DSH web-styling.md 一致)

1. **token 优先**:组件只引用 `--dsw-alias-*` 语义别名,不直接抄静态色阶值,禁止写死颜色。
2. **浅色 / 深色分支属于主题所有者**:`ui-theme` 负责 light/dark 覆盖;功能组件 CSS 不写主题选择器。
3. **不使用组件库 / Tailwind / 自有 token**:用 CSS Modules + `clsx`;
4. **主色 / 交互强调色**使用 DSH 的 `--dsw-alias-state-business-primary`(DeepSeek 蓝),
   不用自定义强调色。
5. **字体**:正文 `--dsw-font-family`,代码/终端/数字 `--ds-font-family-code`;
6. **阴影**:`--dsw-shadow-lv1/2/3`,悬浮层用 `--dsw-shadow-lv3`;
7. **状态色**:成功 `--dsw-alias-state-success-primary`、错误 `--dsw-alias-state-error-primary`、
   警告 `--dsw-alias-state-warn-primary`;
8. **圆角 / 边框 / 背景**:`--dsw-alias-border-l1..l4`、`--dsw-alias-bg-base/layer-1..3`、`--dsw-alias-bg-overlay`;
9. **文字**:`--dsw-alias-label-primary/secondary/tertiary/caption/dimmed`;
10. 面向用户文案中文;代码注释英文。

## 3. 禁止

- ❌ 自建 `--dsw-accent` / `--dsw-accent-soft` / `--dsw-font-mono` / `--dsw-shadow-popover` 等历史自有 token。
- ❌ 在组件 CSS 写死颜色(如 `#0f1c2b` / `#41698c` / `#58cfe2` 等旧 cyber 调色)。
- ❌ 覆盖 DSH 主题(`theme.overrideTokens('starhub', …)`),这是旧「Cyber Command Center」遗毒。
- ❌ Vuetify / Material 风格重阴影、发光、渐变交互。

## 4. 新增 UI 流程

1. 查 `ui-theme/src/styles/design-platform.css` + `base.css` + `gradient-shadow-text.css` 是否已有语义别名;
   没有则到 `ui-theme` 补 token(改 DSH 主题所有者),不在功能组件里造 token。
2. 组件用 CSS Modules + `clsx`,只消费 `--dsw-alias-*`;
3. 本文件只维护指向 DSH 事实来源的链接,不复制 token 清单(避免与生成清单漂移)。
